# Лабораторная 5 — SOCKS5 на Go

Из корня проекта на macOS или Linux с Go 1.23 или новее:

```sh
cd lab5
go run . 1080
```

Прокси слушает TCP-порт 1080 на всех IPv4-интерфейсах. По умолчанию используется первый IPv4-сервер из /etc/resolv.conf и UDP-порт 53. Чтобы явно выбрать резолвер, запустите:

```sh
go run . 1080 1.1.1.1:53
```

Проверка из другого терминала:

```sh
curl --noproxy '' --proxy socks5h://127.0.0.1:1080 https://example.org/
```

В браузере выберите SOCKS v5, адрес 127.0.0.1, порт 1080 и включите разрешение имён через SOCKS. Для остановки нажмите Ctrl+C.

## Как работает

Один цикл poll обслуживает неблокирующиеся сокеты. После согласования метода 0x00 клиент может отправить CONNECT с IPv4 или доменом. Для домена прокси запрашивает A-запись через общий UDP-сокет. Если ответа нет, запрос повторяется через две секунды. После трёх попыток клиент получает REP=0x04.

В каждом направлении накапливается до 64 КиБ передаваемых данных. Когда буфер заполнен, прокси приостанавливает чтение с этой стороны. После EOF прокси досылает накопленные данные и закрывает направление записи, сохраняя возможность передачи в обратную сторону. Цикл закреплён за одним системным потоком. Программа не запускает рабочие горутины, сама среда выполнения Go может создавать служебные потоки.
