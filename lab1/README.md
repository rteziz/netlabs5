# Multicast discovery

Приложение обнаруживает другие запущенные копии в локальной сети через UDP multicast.
При появлении, изменении или исчезновении копии выводится список: IP-адрес, уникальный ID и hostname.
Собственные сообщения игнорируются, пропавшие копии удаляются по таймауту.
IPv4 или IPv6 выбирается автоматически по адресу группы.

## Запуск

Нужен Go 1.26 или новее. Из папки `lab1`:

```bash
go build -o mcdisc ./cmd
./mcdisc -group 224.1.1.1
```

IPv6 с явным интерфейсом (замените `en0` на свой):

```bash
./mcdisc -group ff02::1234 -iface en0
```

Остановка — `Ctrl+C`.

| Параметр | Значение по умолчанию | Назначение |
|---|---|---|
| `-group` | обязательный | Multicast IP-адрес |
| `-port` | `9999` | UDP-порт, 1–65535 |
| `-iface` | автовыбор | Включённый интерфейс с multicast и адресом нужного семейства |
| `-interval` | `2s` | Положительный интервал отправки |
| `-timeout` | `6s` | Таймаут, больше интервала |

## Сообщения и проверки

Формат: `MCD2` (сигнатура и версия), ID из 16 hex-символов,
один байт длины hostname, затем hostname. Имя берётся из `os.Hostname()`.
Допускаются ASCII-буквы, цифры, дефисы и точки: до 253 байт всего,
до 63 байт в каждой части между точками; пустые части и дефис по краям запрещены.
Слишком длинное локальное имя автоматически сокращается: каждая часть до 63 байт,
затем всё имя до 253 байт. Дефисы и точки на месте обрезки убираются с конца.
Совпадение сокращённых имён не мешает обнаружению: копии различаются по ID.
Если после сокращения имя некорректно или генератор случайного ID вернул ошибку, запуск прекращается.

Приёмник проверяет версию, ID, hostname и точную длину пакета.
Повреждённые, слишком длинные и старые пакеты `MCD1` игнорируются.
IP берётся из адреса отправителя. Таблица ограничена 1000 копиями;
при заполнении новые ID игнорируются, известные продолжают обновляться.
TTL для IPv4 и Hop Limit для IPv6 равны 1. Ошибки установки интерфейса
или ограничения TTL/Hop Limit останавливают запуск.

Проверка формата не является аутентификацией: отправитель корректного пакета
может выдать себя за другую копию. Приложение рассчитано на доверенную локальную сеть.

## Проверка

```bash
go test -race ./...
go vet ./...
```

Тесты проверяют сокращение hostname и передачу сокращённого имени в пакете.

Для ручной проверки можно запустить команду с одинаковыми группой и портом
в двух терминалах: каждая копия должна показать IP, ID и hostname другой.
На одном компьютере имена и IP могут совпадать, ID будут различаться.
После остановки одной копии другая удалит её после таймаута и очередной очистки
(обычно в пределах `timeout + interval` после последнего сообщения).
Демонстрация нескольких экземпляров не выполнялась.

Если копии не обнаруживаются, проверьте выбранный `-iface`, разрешение входящего
UDP на нужный порт и поддержку multicast в сети.
